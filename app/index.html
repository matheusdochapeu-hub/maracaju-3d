🐙 Pipeline Open-Source GitHub (Celular + Intel HD 530)

Seu notebook usa Intel HD Graphics 530 (sem NVIDIA CUDA). Use qualquer uma das 3 rotas abaixo para gerar o modelo .glb / .obj / .ply e importar na Aba 1:

1. Mais Rápido (Direto no Celular, Grátis)

Use Scaniverse (Android/iOS) → Modo Mesh → Escaneie o quintal/muro → Export GLB → importe na Aba 1.

2. IA de Ponta GitHub (VGGT / MASt3R no Colab Grátis)

Transforma 15–40 fotos comuns do muro/quintal em malha 3D usando facebookresearch/vggt ou naver/mast3r na GPU T4 gratuita do Google Colab (script pronto em tools/colab_3d_reconstruct.py).

3. Mapear GPS das Fotos no Notebook

# 1. Salve as fotos do celular em capturas/muro/ # 2. Extraia GPS + Bússola + Distância da Casa Maracaju 88: python tools/exif_geo_mapper.py # 3. Abra este painel no celular (mesmo Wi-Fi): python run_maracaju_3d.py

4. Interiores com a Scarlet (Sweet Home 3D)

Desenhe a planta interna com medidas exatas no Sweet Home 3D (open-source, levíssimo) → Exportar OBJ → importe na Aba 1 para ver o sol real entrando pelas janelas!
